## Live Demo

Check out the live site: [aminedahouportfilio.netlify.app](https://aminedahouportfilio.netlify.app/)

## Features

- **Modern, minimalist UI:** dark theme with a red glow aesthetic.
- **Responsive design:** optimized for mobile, tablet and desktop.
- **Custom notifications:** styled red toast alerts for form submissions.
- **Formspree integration:** working contact form without a backend.
- **Performance:** fast loading and smooth scroll transitions.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Animations:** Intersection Observer API for scroll reveals
- **Deployment:** GitHub and Netlify (continuous deployment)

## Project Structure

```
├── index.html   # Main structure
├── style.css    # Custom styling and animations
├── script.js    # Interactive elements and form handling
└── assets/      # Images and icons
```

## Run Locally

Clone or download the repository and open `index.html` in your browser. There is no build step.

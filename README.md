# 🚀 Minimalist Developer Portfolio

Welcome to my professional portfolio! This is a clean, performance-optimized personal website designed to showcase my skills and projects as a Digital Development student.

## 🌐 Live Demo
Check out the live site here: [https://aminedahouportfilio.netlify.app/](https://aminedahouportfilio.netlify.app/)

## ✨ Features
- **Modern & Minimalist UI:** Dark theme with a red "Glow" aesthetic.
- **Responsive Design:** Fully optimized for mobile, tablets, and desktops.
- **Custom Notifications:** Stylish red toast alerts for form submissions.
- **Formspree Integration:** Fully functional contact form without a backend.
- **Performance:** Fast loading speeds and smooth scroll transitions.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Animations:** Intersection Observer API for scroll reveals.
- **Deployment:** GitHub & Netlify (CI/CD).

## 📂 Project Structure
- `index.html`: Main structure.
- `style.css`: Custom styling and animations.
- `script.js`: Interactive elements and form handling.
- `/assets`: Images and icons.
